Zipda 사용 가이드

Zipda guide: archive and extract on iPhone, iPad and Mac

한국어 · English

App Store (iOS · macOS)

Zipda는 어떤 앱인가

Zipda는 아이폰과 아이패드, 그리고 맥에서 쓰는 압축·해제 앱입니다. 같은 앱이 iOS와 macOS 모두에서 나와 있으며, 스토어 페이지는 하나의 링크로 연결됩니다. 개발 문서가 내세우는 승부처는 "한글 파일명이 깨지지 않고, 4GB가 넘어도, 분할되어 있어도 열린다"는 것입니다. 윈도우에서 압축한 파일을 아이폰에서 열었더니 파일명이 외계어로 보이거나, 용량이 큰 압축 파일이 열리지 않는 경험이 있다면 바로 그 문제를 겨냥한 앱입니다.

지원하는 포맷

  • 해제와 압축: ZIP, 7z 및 tar 계열(tar, tar.gz, tar.bz2, tar.xz)
  • 해제: RAR, LZH, ALZ
  • 지원하지 않는 것: EGG 파일은 라이선스와 특허 문제로 지원하지 않습니다. RAR로 압축하는 기능도 없습니다. RAR 압축은 라이선스상 제3자 앱이 만들 수 없기 때문입니다.

일부 포맷의 생성 지원은 앱 버전에 따라 다르므로, 최신 상태는 스토어의 버전 내역과 설명을 확인하세요.

시작하기

1. 설치와 첫 실행

아래 스토어 링크에서 앱을 설치합니다. 계정 가입은 필요 없습니다. 개발 문서에 따르면 파일은 기기 안에서 처리되며 광고와 추적이 없습니다.

2. 압축 파일 열기

아이폰에서는 파일 앱에서 압축 파일을 길게 눌러 공유 메뉴로 Zipda를 선택하거나, 앱 안에서 파일을 직접 불러옵니다. 맥에서는 앱 창으로 파일을 끌어다 놓을 수 있고, 아카이브를 놓으면 해제 확인 창이 뜹니다. 여러 개를 한꺼번에 놓으면 순서대로 처리하는 방식입니다.

3. 내용 살펴보고 부분 추출하기

압축 파일 전체를 풀기 전에 목록을 훑어보고 검색하거나, 파일 하나만 미리 볼 수 있습니다. 필요한 파일 하나만 꺼내는 부분 추출도 가능합니다. 이 열어보기·검색·미리보기는 아래의 하루 횟수에 포함되지 않습니다.

4. 암호가 걸린 파일 풀기

암호가 필요한 ZIP, 7z, RAR을 열면 암호를 묻습니다. 한국에서 흔한 전통적 방식(ZipCrypto)의 암호 ZIP도 처리하도록 설계되어 있습니다.

5. 압축하기

파일이나 폴더, 사진과 동영상을 여러 개 골라 압축할 수 있습니다. ZIP에는 AES-256 암호를 걸 수 있고, 윈도우에서 파일명이 깨지지 않도록 하는 "Windows 호환" 프리셋이 있습니다. 4GB를 넘는 ZIP64도 다룹니다.

파일명 복구 기능

오래된 압축 도구는 파일명을 UTF-8이 아닌 지역 인코딩(한국의 CP949/EUC-KR, 일본의 Shift-JIS 등)으로 저장하는 경우가 많아서, 다른 환경에서 열면 글자가 깨집니다. Zipda는 기기 안에서 인코딩을 자동 감지해 올바른 이름으로 보여 주고, 이미 깨진 이름을 고치는 복구 도구도 제공합니다. 다만 아주 짧은 일본어 파일명이 한국어로 오판독될 수 있다는 한계가 개발 문서에 기록되어 있습니다. 결과가 이상하면 인코딩을 바꿔 보세요.

분할 압축 파일

용량이 커서 여러 조각으로 나뉜 압축 파일(예: .zip.001, .z01 등)은 같은 세트를 자동으로 묶어 여는 것이 목표 기능입니다. 모든 조각이 같은 폴더에 있어야 하고, 하나라도 빠지면 풀리지 않습니다. 이 가이드는 해제를 기준으로 설명하며 분할 압축 생성은 다루지 않습니다.

요금과 한도

모든 기능을 무료로 쓸 수 있되, 압축과 해제는 각각 24시간 기준 하루 3회까지입니다. 열어보기, 검색, 미리보기, 파일명 복구는 횟수에 들어가지 않거나 무제한입니다. 횟수를 없애려면 자동 갱신 구독(월간·연간)을 선택할 수 있고, 가격은 스토어에 표시되는 금액을 확인하세요. 광고는 없습니다.

어떤 상황에서 특히 유용한가

회사나 학교에서 윈도우로 만든 자료를 아이폰으로 받아 보는 경우, 메일이나 메신저로 받은 ZIP을 출장지에서 바로 열어야 하는 경우, 사진과 동영상을 여러 장 골라 하나의 압축 파일로 묶어 보내려는 경우가 대표적입니다. 파일 앱의 기본 압축 기능으로 충분한 단순한 ZIP이라면 굳이 별도 앱이 필요 없지만, RAR나 7z처럼 기본 기능이 다루지 못하는 포맷이나 암호, 인코딩 문제가 얽히면 전용 앱이 편해집니다.

실전 팁

  • 받은 압축 파일이 이상하게 열리면 먼저 용량이 정상인지, 분할 파일의 모든 조각이 있는지 확인하세요.
  • 윈도우 사용자에게 보낼 파일은 "Windows 호환" 프리셋으로 압축하면 이름 문제가 줄어듭니다.
  • 암호는 압축 파일과 다른 경로(전화, 다른 메신저)로 전달하세요.
  • 큰 파일을 풀 때는 기기의 여유 저장 공간을 먼저 확인하세요.
  • iOS는 앱이 백그라운드로 가면 작업이 중단될 수 있으므로 해제 중에는 화면을 켜 두는 것이 안전합니다.

문제 해결

암호를 입력했는데 풀리지 않는다

대소문자와 키보드 언어를 확인하세요. 암호가 파일명까지 암호화한 7z라면 파일 목록 자체가 암호 입력 뒤에야 보입니다.

파일명이 여전히 깨진다

파일명 복구에서 다른 인코딩을 시도해 보세요.

분할 파일이 열리지 않는다

조각이 모두 같은 위치에 있는지, 이름이 바뀌지 않았는지 확인하세요.

.egg 파일이다

지원하지 않는 포맷입니다. 보낸 사람에게 ZIP이나 7z로 다시 받으세요.

자주 묻는 질문

개발 문서상 처리는 기기 안에서 이루어지며 파일이 기기를 떠나지 않는다고 설명되어 있습니다. 세부 내용은 개인정보 처리방침을 보세요.

What Zipda is

Zipda is an archive and extract app for iPhone, iPad and Mac. The same app is available on iOS and on macOS, linked from a single store page. The promise in its development notes is that filenames do not turn into garbage, files over 4 GB still open, and split archives still open. If you have ever opened a Windows-made archive on an iPhone and seen unreadable filenames, or hit a large archive that would not open, that is the problem this app targets.

Supported formats

  • Extract and create: ZIP, 7z and the tar family (tar, tar.gz, tar.bz2, tar.xz)
  • Extract only: RAR, LZH, ALZ
  • Not supported: EGG files are not supported because of licensing and patent concerns. There is also no RAR creation, since the RAR format cannot be written by third-party apps under its license.

Which formats can be created varies by app version, so check the store description and version notes for the current state.

Getting started

1. Install and first launch

Install from the store links above. No account is needed. According to the development notes, files are processed on the device, and there are no ads and no tracking.

2. Open an archive

On iPhone, long-press an archive in the Files app and choose Zipda from the share menu, or import a file inside the app. On Mac you can drag a file onto the app window; dropping an archive brings up an extraction confirmation, and dropping several processes them one after another.

3. Browse and extract part of an archive

Before extracting everything you can scan the list, search it, or preview a single file. You can also pull out just one file. Opening, browsing, searching and preview do not count toward the daily limit described below.

4. Open a password-protected archive

Opening an encrypted ZIP, 7z or RAR prompts for the password. The app is designed to handle the traditional ZipCrypto scheme still common in password-protected ZIP files, as well as newer ones.

5. Create an archive

Pick files, folders, or several photos and videos to compress. ZIP can be protected with AES-256, and a Windows-compatible preset helps filenames survive on Windows. ZIP64 archives over 4 GB are handled as well.

Filename repair

Older archive tools often store filenames in a regional encoding rather than UTF-8, such as CP949 or EUC-KR in Korea and Shift-JIS in Japan, so the names look broken when opened elsewhere. Zipda detects the encoding on the device and shows the correct names, and provides a repair tool for names that are already garbled. The development notes record one limitation: very short Japanese filenames can be misread as Korean. If a result looks wrong, try a different encoding.

Split archives

Archives divided into several parts (for example .zip.001 or .z01) are meant to be grouped into one set and opened together. All parts must be in the same folder, and one missing part means it cannot be extracted. This guide covers opening split sets and does not cover creating them.

Pricing and limits

Every feature can be used for free, but extracting and creating are each limited to three runs per rolling 24 hours. Opening, searching, previewing and filename repair are not counted or are unlimited. To remove the limit you can choose an auto-renewing subscription, monthly or yearly; check the price shown in the store. There are no ads.

Practical tips

  • If an archive misbehaves, first check that its size looks right and that every part of a split set is present.
  • For recipients on Windows, create with the Windows-compatible preset to reduce filename problems.
  • Send the password through a different channel (a phone call, another messenger) than the archive.
  • Before unpacking something large, check how much free storage the device has.
  • iOS may pause work when an app goes to the background, so keep the screen on during large extractions.

Troubleshooting

The password is rejected

Check case and keyboard language. With a 7z that also encrypts filenames, even the file list appears only after the password is accepted.

Filenames are still garbled

Try another encoding in filename repair.

A split set will not open

Make sure all parts are in the same place and none was renamed.

The file is .egg

That format is unsupported. Ask the sender for ZIP or 7z.

FAQ

Q. Is it for iPhone or Mac?

Both. An app of the same name exists for iOS and macOS.

Q. Are my files uploaded anywhere?

The development notes describe processing on the device, with files not leaving it. See the privacy policy for details.

Q. Can it create RAR files?

No. RAR is extract-only.

Q. How many free runs do I get?

Three extractions and three creations per day, counted separately.
