About

Mobile app development studio creating simple, practical tools.

Who We Are · 우리는 누구인가

Setlog is a mobile app development studio focused on creating simple, practical tools that solve real everyday problems. We believe that great apps don't need to be complicated – they just need to work well.

Setlog는 실생활의 문제를 해결하는 심플하고 실용적인 도구를 만드는 데 집중하는 모바일 앱 개발 스튜디오입니다. 훌륭한 앱이 복잡할 필요는 없으며, 그저 잘 작동하기만 하면 된다고 믿습니다.

Mission · 미션

To develop intuitive, user-friendly mobile applications that enhance productivity and simplify digital life for users worldwide.

전 세계 사용자들의 생산성을 향상시키고 디지털 라이프를 단순화하는 직관적이고 사용자 친화적인 모바일 애플리케이션을 개발합니다.

What We Do · 우리가 하는 일

We specialize in:

  • Utility Apps: Practical tools for everyday tasks
  • Cross-Platform Solutions: Apps that work seamlessly across iOS and Android
  • Privacy-First Design: Apps that respect user privacy with minimal data collection
  • Offline-First Approach: Tools that work without internet connectivity

다음 분야를 전문으로 합니다:

  • 유틸리티 앱: 일상적인 작업을 위한 실용적인 도구
  • 크로스 플랫폼 솔루션: iOS와 Android에서 원활하게 작동하는 앱
  • 개인정보 보호 우선 디자인: 최소한의 데이터 수집으로 사용자 개인정보를 존중하는 앱
  • 오프라인 우선 접근: 인터넷 연결 없이 작동하는 도구

Our Apps · 우리의 앱

Currently, we've developed:

  • Charcoal Player: A macOS practice player that splits songs into stems, with pitch-preserving speed control and A-B looping
  • slplayer: A lightweight macOS video player that opens MKV and SRT/SMI subtitles out of the box, with dual subtitles and sync adjustment
  • 물타기 (Multagi): A stock averaging calculator for investors to make informed decisions
  • OneSync: Cross-platform file and text sharing without the need for accounts or cloud storage
  • ClaudeMiner: A lightweight macOS visual monitor for Claude Code sessions
  • TimerLync: A countdown timer that stays in sync across iPhone, iPad, and Apple Watch and alarms at the same moment
  • LapLync: A synced stopwatch and lap timer that starts up to 8 devices in the same millisecond, built for coaches and race officials
  • 우리동네로또 (LottoTown): Region-based Korean lotto number recommendations with nearby lucky retailers and QR win checks
  • Zipda: A fast, privacy-first archive tool for macOS — compress and extract with no data collection

현재 다음 앱을 개발했습니다:

  • Charcoal Player: 곡을 스템으로 분리하고 음정 유지 배속·A-B 구간 반복을 지원하는 macOS 음악 연습 플레이어
  • slplayer: MKV와 SRT·SMI 자막이 그냥 열리고 이중 자막·싱크 조정을 지원하는 가벼운 macOS 동영상 플레이어
  • 물타기: 투자자가 정보에 입각한 결정을 내릴 수 있도록 돕는 주식 평균 단가 계산기
  • OneSync: 계정이나 클라우드 스토리지 없이 크로스 플랫폼 파일 및 텍스트 공유
  • ClaudeMiner: Claude Code 세션을 시각적으로 보여주는 경량 macOS 모니터
  • TimerLync: iPhone·iPad·Apple Watch가 같은 잔여 시간을 보여주고 같은 순간에 울리는 동기화 카운트다운 타이머
  • LapLync: 최대 8대 기기를 같은 밀리초에 시작시키는 코치·기록원용 동기화 스톱워치·랩 타이머
  • 우리동네로또 (LottoTown): 주변 명당 판매점 검색과 QR 당첨 확인을 갖춘 지역 기반 로또 번호 추천 앱
  • Zipda (집다): 데이터 수집 없이 빠르게 압축·해제하는 macOS 아카이브 도구
